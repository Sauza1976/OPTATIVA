## Instalación
1.Inicializamos un repositorio Git local con git init.
2.Creamos un repositorio en GitHub (público o privado).
3.Configura el remoto (origin) para sincronizar ambos.
4.Creamos un archivo index.html
5.Añadimos un archivo .gitignore y edítamos para excluir los ficheros que consideramos, minimo .vscode
6.Realizamos el primer commit con el siguiente mensaje: Inicio del proyecto: estructura básica.
7.Ejecuta el comando necesario para sincronizar con GitHub
